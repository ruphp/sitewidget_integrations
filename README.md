# SiteWidget CMS integrations

Интеграции SiteWidget для CMS и интернет-магазинов.

## Пакеты

Собрать установочные архивы:

```bash
./scripts/build-packages.sh
```

Готовые архивы появятся в `dist/`.

## Модули

- `wordpress/sitewidget` - плагин WordPress.
- `joomla/plg_system_sitewidget` - system plugin Joomla.
- `opencart/sitewidget` - extension/module OpenCart 4.

## Минимально поддерживаемые версии

| CMS | Минимальная версия | Статус |
| --- | --- | --- |
| WordPress | 6.0+, PHP 8.0+ | базовая поддержка |
| Joomla | 4.x+, PHP 8.0+ | базовая поддержка, должно работать и на Joomla 5 после проверки |
| OpenCart | 4.x+, PHP 8.0+ | базовая поддержка |

OpenCart 3 пока не заявляем как поддерживаемый. Там отличается структура расширений и событий, поэтому для него лучше сделать отдельный пакет совместимости после проверки на живой установке.

## Установка

### WordPress

1. Собрать архив `dist/sitewidget-wordpress-0.1.0.zip`.
2. В админке WordPress открыть `Плагины -> Добавить новый -> Загрузить плагин`.
3. Загрузить архив и активировать плагин `SiteWidget`.
4. Открыть `Настройки -> SiteWidget`.
5. Указать `publicKey` клиента и выбрать, какие данные авторизованного пользователя передавать в виджет.

### Joomla

1. Собрать архив `dist/sitewidget-joomla-system-0.1.0.zip`.
2. В админке Joomla открыть `System -> Extensions -> Install Extensions`.
3. Загрузить архив.
4. Открыть список плагинов и найти `System - SiteWidget`.
5. Включить плагин, указать `publicKey` и выбрать передаваемые данные пользователя.

### OpenCart

1. Собрать архив `dist/sitewidget-opencart-0.1.0.ocmod.zip`.
2. В админке OpenCart открыть `Extensions -> Installer`.
3. Загрузить `.ocmod.zip` архив.
4. Открыть `Extensions -> Extensions`, выбрать тип `Modules`.
5. Найти `SiteWidget`, включить модуль, указать `publicKey` и сохранить настройки.
6. После установки проверить, что событие вставки скрипта активно. Если в конкретной сборке OpenCart событие не подключилось автоматически, его нужно будет добавить вручную или поправить пакет под эту сборку.

## Общая логика

Каждый модуль хранит `publicKey` клиента и вставляет на сайт скрипт SiteWidget.

Если посетитель сайта авторизован, модуль может передать в виджет выбранные данные:

- ID пользователя сайта;
- ID ролей/групп пользователя сайта;
- email;
- имя.

Эти поля включаются отдельными настройками модуля.

## Особенности CMS

- WordPress передает ID пользователя, роли как slug-строки, email и display name.
- Joomla передает ID пользователя, ID групп, email и name.
- OpenCart передает customer ID, ID группы покупателя, email и имя покупателя.

## Важно

На первом этапе данные передаются в JavaScript как контекст пользователя сайта. Это удобно для фильтрации контента,
истории диалогов и базовой персонализации. Для строгой серверной авторизации позже нужен подписанный серверный токен.
